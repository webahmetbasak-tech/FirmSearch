# SEO and AI visibility evidence matrix

No search rank or AI citation is guaranteed.

| Practice | Class | Decision |
|---|---|---|
| Crawlable SSR HTML and standard links | OFFICIAL | Implemented |
| Correct status codes, canonicals and canonical-only sitemap | OFFICIAL | Implemented |
| People-first, original entity information | OFFICIAL | Required before indexing |
| Visible structured data matching page content | OFFICIAL | Implemented conditionally |
| No special AI schema/meta/file needed for Google AI features | OFFICIAL | No invented markup |
| Allow OAI-SearchBot / Claude-SearchBot / PerplexityBot | OFFICIAL per provider docs | Implemented in robots policy |
| Separate search/user crawlers from training crawlers | OFFICIAL | Implemented; training bots denied by current policy |
| IndexNow on actual add/update/delete events | OFFICIAL Bing | Opt-in script; requires secret and changed URLs |
| Bing AI Performance citation monitoring | OFFICIAL Bing | Post-launch operations step |
| Accurate Google Business Profile and NAP for each provider | OFFICIAL / strong local practice | Provider-owned post-launch work |
| Relevant local citations and editorial links | STRONG EVIDENCE | Outreach opportunity, never automated |
| Clear direct answers, headings and update timestamps | STRONG EVIDENCE | Implemented structurally |
| `llms.txt` materially improves ranking/citations | EXPERIMENTAL | Informational file only; no ranking claim |
| Repeating query variants across many pages | MYTH / spam risk | Explicitly rejected |
| Hidden “AI-only” text, cloaking or keywords | MYTH / prohibited | Explicitly rejected |
| Schema.org-valid markup guarantees a rich result | MYTH | Documentation distinguishes validity from eligibility |
| Fake reviews/ratings improve visibility | MYTH / policy risk | Validator and data policy reject them |

## Post-launch measurement

Log `platform`, `query`, `date`, `cited URL`, and screenshot/reference for the defined AI query set. Treat changes as observations, not causal proof. Monitor Search Console and Bing AI Performance independently from web analytics.
